# Collaborative-E-Learning-System

## Project Description
A web-based system that allows students to collaborate and learn together through online courses and shared resources.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features
- User Registration and Login
- Course Management
- Student Interaction
- Admin Dashboard

## How to Run
1. Import database.sql into phpMyAdmin
2. Run project on XAMPP or local server
3. Open index.php in browser
